Lo que necesitas

Cuatro cosas antes de correrlo
  1. 01Claude Code instalado y andando.
  2. 02Git y una terminal.
  3. 03Bun 1.0 o superior. Lo que más falla: sin Bun, el ./setup se cae. En Windows además, Node.
  4. 04Se instala en ~/.claude/skills/gstack. No toca tus proyectos.

La instalación

Un solo comando
Paso 01
Clónalo y corre el setup
El comando · cópialo tal cual 
git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack && cd ~/.claude/skills/gstack && ./setup
Paso 02
Comprueba que quedó

Abre Claude Code y escribe /. Si aparecen /ship, /review o /qa, está listo.

Paso 03
Si trabajas con equipo, modo equipo

Desde tu repositorio. Deja gstack para todos y se actualiza solo, sin copiar archivos al proyecto.
