SkillQué te da

Antes de instalar nada

Tres cosas que conviene saber
  1. 01Las skills se instalan por carpeta de proyecto (en .claude/skills/) o para todo (en ~/.claude/skills/). Elige a conciencia.
  2. 02Necesitas Node: casi todas se instalan con npx.
  3. 03Una skill es texto que le dice a Claude cómo trabajar: criterio empaquetado, no un modelo distinto.
Lee antes de correr. Estas skills vienen de gente que no conoces y algunas ejecutan scripts. Pídele a Claude que te resuma los SKILL.md de lo que instalaste antes de largarlo a trabajar sobre tu cuenta o tus archivos.

El comando de cada una

Instálalas en cinco minutos
01
Marketing Skills

Abre la terminal en la carpeta de tu proyecto y corre:

Marketing Skills 
npx skills add coreyhaines31/marketingskills

Si se lo pides desde adentro de Claude Code, agrégale -a claude-code o las instala donde Claude no las lee. ¿Solo algunas? --skill cro copywriting.

02
Banana Claude

Se instala como plugin, escribiendo esto dentro de Claude Code:

Banana Claude · dos líneas 
/plugin marketplace add AgriciDaniel/banana-claude
/plugin install banana-claude@banana-claude-marketplace

Pide una API key gratis en aistudio.google.com/apikey.

03
Context Engineering

Es una plantilla de proyecto: la clonas y trabajas adentro.

Context Engineering 
git clone https://github.com/coleam00/context-engineering-intro.git

Tus reglas van en CLAUDE.md, lo que quieres en INITIAL.md, y después /generate-prp INITIAL.md.

04
Remotion

Aquí no hay skill que instalar: armas el proyecto y Claude escribe el video.

Remotion 
npx create-video@latest

Después le pides la pieza en español —«una intro de 5 segundos con el logo»— y él escribe el código.

05
Awesome Claude Skills

Esta no se instala. Es el directorio donde buscas la que te falta: github.com/ComposioHQ/awesome-claude-skills
