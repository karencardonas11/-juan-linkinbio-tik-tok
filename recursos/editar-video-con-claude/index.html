Comentaste Video

Edita video escribiendo, dentro de Claude

Esto es HyperFrames, de HeyGen. Se instala como skills adentro de Claude Code y a partir de ahí le pides el video en español normal: él escribe el HTML cuadro por cuadro y te lo arma.

Avanzado20 min Cinco pasosNecesitas Claude Code y Node

Antes de empezar

Tres cosas obligatorias
  1. 01Claude Code — la app de escritorio (pestaña Code) o la terminal.
  2. 02Node instalado — el instalador corre con npx.
  3. 03Una carpeta de proyecto: las skills se instalan ahí adentro, no en el sistema.

El paso a paso

Cinco pasos y listo
Paso 01
Busca el comando en la fuente

Busca hyperframes quickstart y entra al primer resultado, o ve directo a hyperframes.heygen.com/quickstart. Baja hasta Install the skills y copia el comando de ahí: si lo cambian, esa página está al día.

Paso 02
Pégalo en Claude Code y dale enter

Abre Claude Code, eliges la carpeta del proyecto (Select folder…) y pega:

El comando de instalación 
npx skills add heygen-com/hyperframes --full-depth

El --full-depth es el que usa Juan: baja la versión actual del repositorio completo.

Paso 03
Elige Core Skills en el selector

Te va a preguntar qué grupo instalar. Core Skills. Es lo que da el motor; lo demás son formatos que se agregan después.

Paso 04
Reinicia el agente en esa carpeta

Cierra y abre la sesión para que las cargue. A Juan le quedaron 26 skills.

Paso 05
Comprueba que quedó

Escribe /hyperframes en el chat: si autocompleta, quedó conectado. Los archivos van a .claude/skills/ de tu carpeta.

Qué pedirle

De un pedido en español a un anuncio armado

Le hablas como al editor: qué video es, qué quieres que pase y en qué formato.

El primero, para probar 
Usando /hyperframes, haz una intro de producto de 10 segundos para https://mi-sitio.com
El que usó Juan en el video 
Usando /hyperframes, edítame este video con pantalla dividida, animaciones y subtítulos, en 9:16.
Le subes el archivo al chat y ese es todo el brief. Claude abre su propio editor y arma el video entero escribiendo código HTML de verdad: cada cuadro, cada transición, cada animación.
